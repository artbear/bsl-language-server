# Строковый индекс известного элемента формы (StringIndexAccess)

## Описание диагностики

Диагностика отмечает литеральный строковый индекс, если метаданные коллекции элементов формы позволяют обратиться к тому же элементу через точку. Числовые и вычисляемые индексы допустимы.

## Примеры

```bsl
Элементы["Номер"].Видимость = Ложь;
```

```bsl
Элементы.Номер.Видимость = Ложь;
```
