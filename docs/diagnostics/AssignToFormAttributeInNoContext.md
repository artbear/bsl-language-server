# Присваивание реквизиту формы во внеконтекстном методе (AssignToFormAttributeInNoContext)

## Описание диагностики

В методах управляемой формы с `&НаСервереБезКонтекста` или `&НаКлиентеНаСервереБезКонтекста` контекст формы недоступен.
Присваивание имени реквизита создаёт локальную переменную вместо обновления формы. Обращение через такой реквизит к свойству объекта также ошибочно.
Проверка использует метаданные текущей формы. Явно объявленные локальные переменные и параметры с тем же именем исключаются. Без метаданных проверка не выполняется.

## Примеры

```bsl
// ПолеКартинки — реквизит формы.
&НаСервереБезКонтекста
Процедура ПолучитьКартинку(Картинка)
    ПолеКартинки = ПоместитьВоВременноеХранилище(Картинка); // Ошибка
КонецПроцедуры
```

Используйте `&НаСервере`, если метод должен менять реквизиты формы, либо верните вычисленное значение и присвойте его в контекстном методе.
