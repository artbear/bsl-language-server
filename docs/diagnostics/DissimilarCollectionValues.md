# Неоднородные значения массива

Рекомендация §4.18 предписывает избегать массивов с несопоставимыми типами
элементов. Диагностика сравнивает типы значений при последовательных вызовах
`Добавить` и `Вставить` у одной переменной известного типа `Массив`
на одном прямолинейном участке. Новый экземпляр, другое обращение и
граница ветви начинают отдельную последовательность.

```bsl
Элементы = Новый Массив;
Элементы.Добавить(10);
Элементы.Добавить("десять");
```

Используйте отдельные коллекции или типизированную запись для связанных значений
разных типов. См. [«Строгая типизация»](https://github.com/1C-Company/v8-code-style/blob/c3d043dbd72e82301c99ac29a2743dcc22507cc1/docs/checks/code_typification.md).
