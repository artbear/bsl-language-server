# Несовместимый тип аргумента метода (IncompatibleMethodArgumentType)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

Диагностика отмечает несовместимые аргументы глобального или объектного метода, если можно исключить все подходящие по форме вызова сигнатуры. Каждый вариант проверяется целиком. Если разные аргументы исключают разные варианты, сообщение указывает на несовместимое сочетание.

Сигнатуры берутся из комментариев к методам BSL, синтакс-помощника установленной платформы и типов конфигурации. Для платформы укажите каталог `bin` в `v8platform.binPath` или используйте автоопределение установленной платформы. Для определения примитивных типов параметров в синтакс-помощнике нужны файлы `shlang_*.hbk` той же установки.

Пропуски аргументов проверяются отдельной диагностикой. Если тип аргумента, получателя или параметра нельзя вывести с достаточной точностью, сообщение пропускается. Явное значение `Неопределено` имеет известный тип. Проверка учитывает все типы, объявленные в сигнатуре, включая явно указанные альтернативы и типы значений по умолчанию в объявлениях BSL.

## Пример

```bsl
// Параметры:
//  Данные - Массив - данные отчета.
Процедура ЗаполнитьОтчет(Данные)
КонецПроцедуры

Процедура СформироватьОтчет()
    ЗаполнитьОтчет("строка"); // Ошибка на аргументе
    Данные = Новый Массив;
    ЗаполнитьОтчет(Данные);
КонецПроцедуры
```
