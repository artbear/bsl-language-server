# Смена типа переменной или ключа структуры (TypeChange)

## Описание диагностики

Замечание появляется при присваивании локальной переменной или существующему ключу структуры, если тип нового значения расходится со всеми известными типами в точке присваивания. Начальное и сбрасывающее значение `Неопределено` допустимо.

## Примеры

```bsl
Сумма = 10;
Сумма = "Десять";
```

```bsl
Сумма = 10;
ПредставлениеСуммы = "Десять";
```
