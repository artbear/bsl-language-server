# Переменная инициализируется в цикле или условии

Диагностика отмечает чтение локальной переменной после цикла или условия,
если к нему ведёт путь без присваивания. Явная инициализация до цикла и
инициализация на каждой ветви устраняют такой путь.

```bsl
Для Каждого Строка Из Строки Цикл
    ПоследняяСтрока = Строка;
КонецЦикла;
Обработать(ПоследняяСтрока);
```

При пустой коллекции цикл пропускается. Инициализируйте
`ПоследняяСтрока` до цикла, например значением `Неопределено`, и
обработайте это состояние при чтении.

См. раздел «Инициализация локальных переменных» в
[рекомендации «Строгая типизация»](https://github.com/1C-Company/v8-code-style/blob/c3d043dbd72e82301c99ac29a2743dcc22507cc1/docs/checks/code_typification.md).

Числовой «Для» задаёт счётчик до проверки границы. Чтение прежнего значения
в выражении инициализации происходит до этой записи.
