# Тип возвращаемого значения функции неизвестен (MissingReturnType)

## Описание диагностики

Замечание появляется в выражении после `Возврат`, если тип выражения неизвестен и у функции нет объявленного типа результата. Для экспортных функций явное описание отдельно проверяет MissingTypeDescription. Доступ к отсутствующему члену результата известного типа проверяет [UnknownMember](UnknownMember.md).

## Примеры

```bsl
Функция ПолучитьСтроку()
    Возврат ВнешняяБиблиотека.Получить();
КонецФункции
```

```bsl
// Возвращаемое значение:
//  Строка - значение из внешней библиотеки.
Функция ПолучитьСтроку()
    Возврат ВнешняяБиблиотека.Получить();
КонецФункции
```
