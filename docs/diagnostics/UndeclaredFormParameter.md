# Параметр управляемой формы не объявлен (UndeclaredFormParameter)

## Описание диагностики

При обращении к отсутствующему члену свойства `Параметры` в модуле управляемой формы добавьте параметр в редакторе формы. Это относится и к необязательным параметрам. Стандартные параметры и параметры из метаданных считаются объявленными.

[UnknownMember](UnknownMember.md) обнаруживает такие обращения при общей проверке членов. Отдельный ключ позволяет включить проверку только для параметров формы.

## Пример

```bsl
// РежимПодбора должен быть объявлен в форме.
Режим = Параметры.РежимПодбора;
```
