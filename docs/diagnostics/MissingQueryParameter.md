# Пропущенный параметр запроса (MissingQueryParameter)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

Правило проверяет параметры текста объекта `Запрос` перед вызовами `Выполнить`, `ВыполнитьПакет` и `ВыполнитьПакетСПромежуточнымиДанными`. Замечание указывает на первое вхождение имени в языке запросов. Связанные позиции указывают на вызовы выполнения. Регистр имени роли не играет.

Если параметр установлен только на некоторых достижимых путях, сообщение указывает на возможный пропуск. Для незапущенного локального запроса правило проверяет также нормальный выход из метода, пока объект остаётся внутри метода. Установка после выполнения действует при следующем вызове.

Анализ учитывает присваивания текста, ссылки на один экземпляр, константные склейки и замены, а также вызовы однозначно определённых помощников в том же модуле. При динамическом тексте или непрозрачном изменении запроса замечание требует независимого пути с известным состоянием.

## Примеры

Вызов в этом примере может получить запрос без параметра `Склад`.

```bsl
Запрос = Новый Запрос("ВЫБРАТЬ &Склад КАК Склад");
Если ЕстьОтбор Тогда
    Запрос.УстановитьПараметр("Склад", ВыбранныйСклад);
КонецЕсли;
Возврат Запрос.Выполнить();
```

Если запрос должен выполняться только при наличии отбора, перенесите выполнение в ту же ветвь. Если параметр нужен всегда, установите его перед условием.
