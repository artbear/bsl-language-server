# Несхожие типы в составном типе (DissimilarCompositeType)

## Описание диагностики

Замечание появляется, когда в описании параметра или возвращаемого значения объединены типы с разными интерфейсами. Например, строка и объект справочника, число и массив, таблица и дерево значений. Объединение разных ссылок на справочники допустимо. Служебные значения `Неопределено` и `Null` не влияют на проверку. Выведенные типы не проверяются.
