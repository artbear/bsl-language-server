# Обращение к члену значения без типа (UntypedMemberAccess)

## Описание диагностики

Диагностика отмечает обращение к свойству или методу, если во всех рассматриваемых контекстах тип получателя остался неизвестным. В цепочке отмечается первое обращение с неизвестным получателем. Явный тип `Произвольный` допустим. Ошибки в именах членов известного типа проверяет [UnknownMember](UnknownMember.md).

## Примеры

Тип параметра неизвестен в точке вызова `Количество()`.

```bsl
Процедура ВывестиКоличество(Вход) Экспорт
    Сообщить(Вход.Количество());
КонецПроцедуры
```

В описании параметра указан массив.

```bsl
// Параметры:
//  Вход - Массив - элементы для подсчёта.
Процедура ВывестиКоличество(Вход) Экспорт
    Сообщить(Вход.Количество());
КонецПроцедуры
```
