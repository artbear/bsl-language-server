# Произвольный параметр передаёт структуру инициализации формы

Правило проверяет вызов `ОткрытьФорму`, когда анализатор находит конкретную
управляемую форму и знает состав передаваемой структуры. Оно отмечает передачу
вложенной структуры в объявленный параметр формы произвольного типа.

```bsl
Данные = Новый Структура("РежимПодбора", Истина);
ОткрытьФорму("Документ.Заказ.Форма.ФормаДокумента", Новый Структура("Данные", Данные));
```

Объявите `РежимПодбора` отдельным параметром формы и передайте его в общей
структуре параметров открытия. См. раздел «Использование параметров формы» в
[рекомендации «Строгая типизация»](https://github.com/1C-Company/v8-code-style/blob/c3d043dbd72e82301c99ac29a2743dcc22507cc1/docs/checks/code_typification.md).

Произвольный параметр скрывает имена и типы вложенных полей от проверки в IDE.
Опечатка в ключе или значение другого типа могут проявиться при запуске формы.

Объявите «РежимПодбора» с типом «Булево» в редакторе формы и передайте его напрямую.

```bsl
ОткрытьФорму("Документ.Заказ.Форма.ФормаДокумента", Новый Структура("РежимПодбора", Истина));
```
