# Присваиваемое значение не соответствует типу поля

Диагностика сравнивает тип присваиваемого значения с типом отдельного поля,
заданным в документирующем комментарии для переменной или параметра.
Проверяются именованные поля и запись в структуру через `Вставить`.

```bsl
// Параметры:
//  Данные - Структура:
//  * Сумма - Число
Процедура Обновить(Данные)
    Данные.Вставить("Сумма", "10");
КонецПроцедуры
```

Присвойте `10` числом, если поле хранит сумму. См.
[«Строгая типизация»](https://github.com/1C-Company/v8-code-style/blob/c3d043dbd72e82301c99ac29a2743dcc22507cc1/docs/checks/code_typification.md).

Правило пропускает вычисляемые ключи, поля без явного описания и пары,
в которых один из типов не удалось разрешить. Такой пропуск оставляет
совместимость типов непроверенной.

Для локальной переменной с полями используйте ссылку «См.» на функцию,
описание которой перечисляет поля результата. Парсер сохраняет поля из
описаний параметров и возвращаемых значений методов.
