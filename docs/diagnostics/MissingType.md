# Тип переменной не задан при инициализации

При первом присваивании локальной переменной тип значения должен определяться из
выражения или описания переменной. Диагностика проверяет инициализацию простым
присваиванием в экспортных и неэкспортных методах.

В обычном режиме правило действует в модулях с `//@strict-types` перед первым
семантическим объектом. Явное включение `MissingType` в конфигурации позволяет
проверять модули без аннотации.

```bsl
Данные = ЗагрузитьДанные();
```

Если контракт загрузки гарантирует структуру, укажите тип:

```bsl
Данные = ЗагрузитьДанные(); // Структура
```

См. рекомендацию [«Строгая типизация»](https://github.com/1C-Company/v8-code-style/blob/c3d043dbd72e82301c99ac29a2743dcc22507cc1/docs/checks/code_typification.md).

Явное описание «Произвольный» допускает намеренно динамический контракт.
Выведенный «Произвольный» без такого описания оставляет тип значения неизвестным.
